# mojique-difficulty-mod
Mojique Mod that adds 3x HP to the enemies, for increased difficulty

The game felt a bit too easy and had no real use for drinks. I've seen this said by multiple people say it so I decided to do something about it and ran through the values of all enemies' hp.

SOME FIGHTS MAY BE UNBALANCED! I tested it in a boss fight + random encounters but only in one area, please let me know if you find the wettings too often/rare and if some fights are too hard (Make sure to stack up on potions from vendors, I wanted to give them more purpose!)

All changes:

- EVERY enemy has 3x original hp!

- All girls have lesser chance to wet themselves from being damaged/Using skills. I've done this as fights with 3x HP take significantly longer, thus increasing chance of wetting, which normally don't account for such fight length. Overall it SHOULD make the wettings (Due to dmg/skill usage) per fight be similiar to original.

 

Install guide:

1. Get mojique english edition. I don't think it'll work with japanese, but not sure.

2. Go to the folder then -> Data -

3. Find "CommonEvents" and move it out of the folder/rename it to "CommonEventsEASY". This is done so you can swap to regular difficulty at any time, in case of some fights being too hard/impossible. Rename it back to change the difficulty back. 

4. Put the installed file from here into the same Data folder. 

5. Enjoy!
